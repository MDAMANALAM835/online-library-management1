# Online Library Management Website

## About Project
An online library website where students can search
and explore different books.

## Features
- Home page
- Book collection
- Search books
- Category filtering
- About section
- Contact section

## Technologies
- HTML
- CSS
- JavaScript
- GitHub
- AWS EC2
- AWS S3

## AWS Services
- EC2: Website hosting
- S3: Book PDF and image storage
